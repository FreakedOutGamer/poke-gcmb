# Pokémon Colosseum Bonus Disc (Japanese sample)

This is a decompilation of `sample0519.bin`, an earlier, Japanese-language
sample build of the Jirachi distribution, left on the Pokémon Colosseum
Bonus Disc.

It builds the following image:

* **sample0519.mb** `sha1: fe72fb983b623aa560df84e9d269e7a21db937e4`

It is in the Bonus Disc (PC6E01)'s `files/tgc/pokedownload.tgc`, an embedded
GameCube image with its own file system, beside the files
[client](../client/README.md) builds.

To set up the repository, see [INSTALL.md](../INSTALL.md).

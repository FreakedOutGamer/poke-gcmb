# Pokémon Colosseum Bonus Disc

This is a decompilation of the multiboot program that distributes Jirachi
from the Pokémon Colosseum Bonus Disc, in both known revisions.

It builds the following images:

* **client_2003_1112.mb** `sha1: 446b9a3d3abe45236ef4a378e6469496ae85aa5c`
* **client.mb** `sha1: 39287eeba84ca1c4c4e4eeed36fcc36390364b99`

Both are in the Bonus Disc (PC6E01)'s `files/tgc/pokedownload.tgc`, an
embedded GameCube image with its own file system, as `client.2003_1112.bin`
and `client.bin`.

To set up the repository, see [INSTALL.md](../INSTALL.md).

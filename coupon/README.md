# Pokémon Colosseum (Poké Coupon link)

This is a decompilation of `coupon.bin`, the multiboot program Pokémon
Colosseum sends to Ruby and Sapphire for its Poké Coupon link: trading
Pokémon, Poké Coupons and battle data with the GameCube.

It builds the following image:

* **coupon.mb** `sha1: 9f170f72a7b06ee1e533f1e3c6812e810f772784`

Every disc carries the same file: Pokémon Colosseum (GC6J01, Japan; GC6E01,
USA; GC6P01, Europe) as `files/coupon.bin`, and the Pokémon Colosseum
Expanded Disc (PCKJ01) and Nintendo Special Disc (PCSJ01) inside
`files/tgc/pokecolo_ex.tgc`. Its text is Japanese even on the US and
European discs.

To set up the repository, see [INSTALL.md](../INSTALL.md).

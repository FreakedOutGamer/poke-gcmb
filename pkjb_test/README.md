# Pokémon Colosseum (pkjb_test)

This is a decompilation of `pkjb_test`, a test multiboot program left on the
Japanese and European Pokémon Colosseum discs. It shows a "download
successful" screen.

It builds the following image:

* **pkjb_test.mb** `sha1: 215e873588838def7c52e118682a1b33c6d6eb6a`

Pokémon Colosseum (GC6J01, Japan; GC6P01, Europe) carries it as
`files/pkjb_test.bin`.

To set up the repository, see [INSTALL.md](../INSTALL.md). `make png`
renders the screen to `build/graphics/test_screen.png`.

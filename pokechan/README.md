# Pokémon Channel

This is a decompilation of the multiboot program that distributes Jirachi
from Pokémon Channel.

It builds the following image:

* **pokechan.mb** `sha1: 32429c491ae83f84b2a71fe5523fccd215aaab59`

Both PAL discs, Pokémon Channel (GPAP01, Europe; GPAU01, Australia), carry
it as `files/pokechan.bin`.

To set up the repository, see [INSTALL.md](../INSTALL.md).
